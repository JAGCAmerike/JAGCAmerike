# ¿Qué es Git?
  Un sistema de control de versiones distribuido que facilita colaboracion entre equipos.

---
# ¿Qué es GitHub?
  Una plataforma de Microsoft en la que se companten repositorios.
  
---
# Diferencia entre Git vs GitHub
  Git es el software que se utiliza para realizar el control de versiones y Gthub es la plataforma mas popular para manejarlo de forma remota y colaborativa.
  
---
# ¿Qué es un commit?
  Es el reporte de un cambio efectuado dentro del repositorio como la actualizacion o agregacion de un archivo.

---
# ¿Qué es un branch?
  Es la seccion de un repositorio separada de la principal en la que se pueden realizar cambios y pruebas sin afectar a la principal.

---
# ¿Qué es un Pull Request (PR)?
  Es el proceso de reportar un cambio al contenido del repositorio en el que se solicita la integracion del cambio al contenido principal.
